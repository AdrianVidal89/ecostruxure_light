Upload an .xlsx with one requirement per row. Expected columns (headers, case-insensitive): sub_system, req_gravity, req_operation, req_functional, req_category, description, validation_criteria, life_cycle_phase, reference_documentations, remarks, use_cases. The code is generated automatically. req_gravity, req_operation, req_functional and req_category accept either a value or its label from the suggested list below — but they're not limited to it: any other text is accepted too and saved as a new suggestion for this POC, available next time (from the importer or the "+ Add new…" option on the manual form). use_cases is optional — a comma-separated list of existing use case codes to link; leave it blank (or omit the column) and the requirement is imported with no use cases linked. A requirement has no title, so validation_criteria is used to catch duplicates: a row whose validation criteria matches one already in this POC (or an earlier row in the same file) is flagged and skipped — safe to re-upload the same sheet without creating copies.
