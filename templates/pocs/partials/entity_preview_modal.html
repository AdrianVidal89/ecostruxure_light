{% comment %} Single shared preview popup — the only copy of this modal shell in the whole app (included once, in base.html). Every link/chip that references a Use Case, Requirement, Test or section calls window.openEntityPreview(previewUrl, detailUrl, label) (see static/js/entity_preview.js); the fragment is fetched via htmx into #entity-preview-body, and "Go to …" navigates exactly like a direct visit to that entity's own page. Navigation (spec item 1): opening a preview from inside another preview pushes a breadcrumb trail (#entity-preview-trail) instead of replacing the view outright — "Back" (#entity-preview-back) restores the previous context so the user never loses their place (e.g. Test -> Requirement -> Test again). {% endcomment %}
